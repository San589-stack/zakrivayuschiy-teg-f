# Закрывающий тег

Финальная проектная работа модулей вёрстки: адаптивная страница из восьми карточек, где каждая карточка — этап учебного пути. К каждой карточке можно поставить лайк, а кнопка «Сохранить на память» открывает модальное окно.

## Ссылки

- Репозиторий: https://github.com/San589-stack/zakrivayuschiy-teg-f
- Ссылка на сайт: https://san589-stack.github.io/zakrivayuschiy-teg-f/

## Что реализовано

- Адаптивная вёрстка под ширину от 320 px, контрольная точка 375 px.
- Резиновая шапка на `clamp()` и общая ширина контента в CSS-переменной.
- Фиксированный фон из трёх градиентов.
- Шрифты: вариативный Inter (`font-variation-settings`) и Press Start 2P.
- Карточки с водяным знаком: `mix-blend-mode: hard-light`, обводка через `-webkit-text-stroke` с запасным `text-shadow` в `@supports`.
- CSS-фильтры на картинках карточек.
- Анимация сердца: наведение, нажатие и лайк (переходы `fill`, `@keyframes` для пульса и искр).
- Кнопки с эффектом заливки и режимом смешивания `difference`, состояния `hover` и `focus-visible`.
- Модальное окно на элементе `<dialog>` со стилизованным `::backdrop`.
- Фавиконы: `ico`, `svg` и иконка для iOS.
